# Waystones — Fast Travel Mod

[![Download Latest](https://img.shields.io/github/v/release/Outerclosocket/waystones-teleport-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Outerclosocket/waystones-teleport-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Place magical Waystones around your world to teleport between them instantly, with configurable costs.

![Waystones — Fast Travel Mod Preview](https://cdn.modrinth.com/data/LOpKHB2A/images/6f91f54ef37b6b19c06685231d81f03d28601e6d_350.webp)

## Features

- Craft and place Waystones for instant fast travel
- Warp Scroll and Return Scroll for one-time teleports
- Villager Waystones generate naturally in villages
- Configurable XP or item cost per teleport
- Global Waystones accessible from anywhere on the map

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
